# Student Analytics Toolkit

The Student Analytics Toolkit is a Python terminal program that generates student data, cleans records from a file, converts the records into student objects, performs class analysis, filters passing students, and exports reports.

## Features

- Generates sample student data.
- Stores data in a text file.
- Cleans names and scores when loading data.
- Uses Student and HonoursStudent classes.
- Displays all students and their grades.
- Calculates the class average.
- Finds the highest and lowest scores.
- Calculates the pass rate.
- Uses a generator to display passing students.
- Uses a closure for custom pass marks.
- Displays environment and date reports.
- Exports analysis results to a report file.
- Records activities in a log file.
